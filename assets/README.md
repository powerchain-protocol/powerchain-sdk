# Assets

> **Brand Assets, Design Resources & Media Library for the PowerChain Platform™**

The `assets/` directory contains the official visual identity, brand resources, architecture diagrams, product illustrations, icons and design assets used throughout the PowerChain Platform™ documentation, SDKs, websites and developer ecosystem.

These assets provide a consistent visual language across documentation, applications and enterprise presentations.

# Design Principles

All assets follow the official PowerChain™ design language.

- Enterprise-first visual identity
- Minimal and modern layouts
- Clean typography
- Grid-based composition
- Glassmorphism where appropriate
- High accessibility and readability
- Consistent spacing and alignment
- Scalable vector graphics (SVG)
- Retina-ready raster assets
- Optimised for web and documentation

# Usage Guidelines

When using PowerChain™ assets:

- Use only official logos and icons.
- Maintain the original aspect ratio.
- Do not modify colours or typography.
- Ensure adequate clear space around logos.
- Use SVG assets whenever possible.
- Optimise raster images for web delivery.
- Follow the official brand guidelines.
